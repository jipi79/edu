# 화면 규칙과 검증

## 화면

- 16:9 와이드(13.33 × 7.5 in), 흰 바탕 내용 장 + 어두운 표지·정리 장. 글꼴은 맑은 고딕.
- 학년군별 글자 크기는 `tools/pptx/build_lesson.js` 의 `BAND` 에 있다(초5·6 제목 40pt, 본문 28pt, 보조 22pt). 내용이 넘치면 먼저 문장을 줄이거나 장을 나눈다. 보조 글자보다 작게 줄이지 않는다.
- 블록 좌표는 인치 단위. 가장자리 0.5in 이상, 바닥글(6.9in 아래) 침범 금지. `check_lesson.py` 가 검사한다.
- 줄바꿈이 숫자와 단위를 가르면("1 / 칸") 문장을 바꾸거나 `\n` 으로 직접 줄을 나눈다.

## 접근성

- 모든 장에 제목 개체 틀(type=title)이 있다. 그림(막대·격자)마다 대체 설명(`alt`)을 쓴다.
- 색만으로 정답·범주를 구별하지 않는다. ○/×, ≠, 가·나·다 같은 글자·기호를 함께 쓴다.
- 정답 공개는 별도 장으로 하고 애니메이션에 의존하지 않는다.

## 검증 순서

1. `check_lesson.py`: 스키마, 목표 연결, 교육과정 연결, 정답 검산, 그림-표기 일치, 안전 영역.
2. `check_output.py`: 장 수, 제목, 경계, 노트(수업용 있음/학생용 없음), 학생용의 교사 전용 요소 제거, 대체 설명.
3. 렌더링한 모든 장과 PDF를 사람 눈으로 확인: 넘침, 겹침, 잘림, 낮은 대비, 어색한 줄바꿈.
4. 자동 검사가 볼 수 없는 것은 내용 검토로 판단한다: 수업의 자연스러움, 어휘 수준, 그림의 의미.
5. 실제 PowerPoint에서 열어 보지 못했다면 그렇다고 기록한다(이 환경의 미리보기는 LibreOffice이며 맑은 고딕 대신 나눔고딕으로 그린다).
