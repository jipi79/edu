# 과목 유형별 규칙

해당 과목 파일만 읽는다. 아직 없는 유형은 아래 표를 기준으로 하고, 첫 시범 수업을 만들 때 파일로 옮긴다.

| 수업 유형 | 수업의 중심 | 적절한 학습 증거 |
|---|---|---|
| 국어·영어 | 글·대화·매체를 읽거나 듣고 의미를 구성한 뒤 말하거나 쓴다 | 요약, 근거 찾기, 실제 발화, 글 고쳐 쓰기 |
| 수학 (`math.md`) | 구체물·그림을 식에 연결, 풀이 시범 후 도움을 줄여 간다 | 풀이 과정, 다른 표현, 오류 설명 |
| 자연과학 | 질문·예측·관찰 또는 실험·자료 해석·설명 | 기록, 변인 구분, 증거에 근거한 설명 |
| 사회·역사 | 지도·통계·사료의 작성 배경을 확인하고 여러 자료 비교 | 출처 판단, 원인과 결과, 근거 있는 해석 |
| 도덕·윤리·인문 | 사례의 쟁점, 개념·이유·반론 검토 | 근거의 타당성, 상대 관점 검토, 성찰 |
| 정보·기술·가정 | 요구 파악·설계·실행·시험·수정 | 작동 결과, 오류 수정, 선택 이유 |
| 음악·미술·체육 | 감상·시범·실제 표현과 수행·피드백 | 연주·작품·동작, 수정 과정 |
| 보건·안전·진로·환경 | 상황 판단, 생활 속 실천·탐색·프로젝트 | 실천 계획, 상황별 대응, 활동 기록 |

공통 금지
- 과학 관찰 결과를 실험 전에 정답처럼 제시하지 않는다.
- 역사적 해석을 한 문장으로 단정하지 않는다.
- 음악·체육의 실제 수행을 PPT 읽기로 대신하지 않는다. PPT는 짧은 안내, 활동지는 관찰 기준표로 만든다.
- 심리·종교·윤리는 개인 신념의 일치가 아니라 개념 이해와 이유 제시를 평가한다.
- 한글 해득, 영어 발음·듣기처럼 소리가 필요한 내용은 음성 자료를 함께 준비하고, 없으면 그 제약을 안내서에 적는다.
