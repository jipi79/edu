# 활동형 차시(음악·미술·체육·기술·가정·진로·환경, format: act)

- 화면은 짧은 안내다. 실제 표현·운동·만들기·실천은 화면 밖에서 하고, 장 수는 6~8장.
- 흐름: cover → (prior) → concept 또는 cards(무엇을 왜) → activity(단계 2~5, 관찰 기준 2~4, 안전) → compare/practice(생각해 보기) → activity 또는 check(혼자 해 보기·발표) → summary.
- 관찰 기준(`criteria`)은 부모가 보고 판단할 수 있는 행동으로 쓴다(“박이 일정해요”, “가위 날을 몸 반대쪽으로 향해요”).
- 체육·안전: 집 안에서 할 수 있는 동작으로, 공간·바닥·가구 위험을 확인하는 안전 문구를 넣는다. 응급 처치는 “어른에게 알리고 119에 신고”를 기본으로 하고, 의료 처치를 아이에게 맡기지 않는다.
- 보건·성(사춘기, 신체 경계, 동의)은 정확한 용어와 차분한 말투로, 도움을 청할 어른·기관(보호자, 선생님, 117 학교폭력 신고, 1388 청소년 상담)을 알려 준다.
- 미술·음악 작품을 화면에 옮기지 않는다(저작권). 작품 감상은 부모가 함께 찾아보는 활동으로 안내한다.
- 활동지: 관찰 기준 체크표, 실천 기록표(날짜·한 일·느낀 점), 만들기 설계 그림 칸(`box`).
