# 수학

- 구체물(종이 띠, 바둑돌) → 그림(막대, 격자, 수직선) → 식의 순서로 옮긴다. 같은 장에서 그림과 식을 나란히 둔다.
- 그림은 정확해야 한다. 분수 막대·격자는 `bar`, `grid` 블록으로 그려 칸 수와 색칠 수가 데이터 그대로 나온다. 생성형 이미지로 수량을 나타내지 않는다.
- 분수는 세로 표기(`frac`, `eq`, `eqx` 블록)로 쓰고, 문장 안에서는 "4분의 3"처럼 읽는 말로 쓴다.
- 같은 양을 비교할 때는 같은 전체(같은 길이의 막대)를 위아래로 맞추고 점선 기준선(`vline`)을 첫 막대의 색칠 끝에 둔다. `check_lesson.py` 가 기준선 위치와 분수 표기 옆 그림의 색칠 비율을 검사한다.
- 시범 → 안내 연습(도움말 포함) → 혼자 하기 순서로 도움을 줄인다. 혼자 하기에는 방법 설명을 함께 요구한다.
- 흔한 오개념(예: 분자·분모에 같은 수를 더하기)은 반례 그림으로 직접 다룬다. "항상 성립하는가"를 묻고, 예외가 있으면 노트에 정확히 적는다.
- 선수 관계가 촘촘하다. 선수 학습이 비면 그 차시보다 앞 학년의 해당 항목을 먼저 한다.

## 중학교(M) 견본에서 정한 것 (중1 소수와 합성수·정수와 유리수의 덧셈)

- 견본: `lessons/G07_중1/MAT_수학/소인수분해/KR22-G07-MAT-PRIME-L01.json`, `…/정수와유리수/KR22-G07-MAT-INTADD-L01.json`. 구조는 초6과 같다(표지 → 선수 확인 → 개념·풀이 단계 → 안내 연습 → 오개념 비교 → 혼자 하기 → 정답(teacher_only) → 마무리 확인 → 정리 → 보충).
- 새 용어(소수·합성수·거듭제곱·밑·지수·양수·음수·절댓값 등)는 처음 나오는 장에서 뜻을 함께 쓴다. 노트에는 읽는 법도 적는다(3⁴ = 3의 네제곱).
- 처음 거듭제곱을 보이는 장은 `blocks`로 크게 그려도 된다(밑·지수 카드와 같은 색). 그 밖에는 위첨자 문자(2³)를 그대로 쓴다.
- 부호 있는 계산은 수직선 이동 모형으로 먼저 보이고(더하기 이동과 빼기 이동은 `jumps` 의 `color` 로 구별), 그다음 절댓값 규칙으로 일반화한다. 견본의 `geo` 수직선도 쓸 수 있다.
- 부호 있는 분수는 `eq` 에서 부호와 괄호를 한 글자 항목으로 묶어 쓴다: `["(−",[1,2],") + (−",[1,3],") = −",[5,6]]`. 정리 장 복습 문제에는 분수를 넣지 않는다(작아진다).
- 계산 답은 모두 `checks`(음수 답은 `blank`·`compare`). 생성 스크립트에서 assert로 한 번 더 검산한다(소수 목록, 약수 개수, 합).
- 답을 "+2"처럼 부호를 붙여 쓰는지, 노트에 이 단원의 약속을 적는다.

### 근호 표기 (중3 제곱근 단원에서 정함)

- 근호는 `√`(U+221A) 바로 뒤에 수를 붙여 쓴다(√2, √12, √0.09). 계수와 문자는 근호 앞에 쓴다(2√3, −2√3, a√2). 플러스마이너스는 ±√7.
- 근호 안이 거듭제곱·곱·식이면 괄호로 묶는다: √(3²), √((−3)²), √(2² × 3), √(ab). 근호의 제곱은 (√3)² 로 쓰고 √3² 처럼 모호하게 쓰지 않는다.
- 분수와 함께 쓸 때는 `eq` 분수 칸에 근호를 넣는다: `[1,"√2"]`, `["√2",2]`, `[3,"2√3"]`. √(분수)는 eq로 그리지 못하므로 √a/√b, √(15 ÷ 3) 또는 말("9분의 4의 제곱근")로 쓴다.
- 미리보기(LibreOffice)에서는 한글 뒤에 띄어 쓴 √와 −가 뒤의 숫자와 벌어져 보인다. 근호·빼기 기호는 줄 맨 앞이나 `:` `=` `,` `(` 숫자·영문자·± 바로 뒤에 둔다(예: "한 변의 길이: √2").
- 노트에는 읽는 법을 적는다: 루트 2, 플러스마이너스 루트 2, 2분의 √3.
- 근호가 든 답도 `checks` 에 화면 그대로 넣는다(`authoring.md` 의 정답 검산 참고). 생성 스크립트에서는 a√b(b는 제곱인수 없는 수)로 정확히 계산해 assert한다(견본 생성기: `tools/examples/middle/` 의 `radical.py`).

### 고등학교 표기 (고1 다항식·복소수에서 정함)

- 다항식 답은 내림차순으로 쓴다. 긴 나눗셈은 `geo` 격자(차수마다 한 칸, 몫은 위, 뺄 식은 파랑)로, 조립제법은 `geo` 격자(왼쪽에 나누는 수, ㄴ자 선, 나머지는 짧은 선으로 떼어 초록)로 그린다. 견본: `lessons/G10_고1/MAT_수학/공통수학1다항식/`.
- 허수단위는 i(i² = −1), 복소수는 a + bi. a > 0일 때 √(−a) = √a i 로, 근호 뒤에 줄바꿈 없는 공백을 두어 `√3 i`, `2√3 i` 처럼 쓴다(`√3i` 는 쓰지 않는다). 정수 계수는 붙여 쓴다(2i, −i, ±3i). 근호 안이 음수이면 괄호로 묶는다: √(−4) = 2i.
- 복소수 답은 검산기가 i를 읽지 못하므로 실수부분·허수부분을 따로 `blank` 로 넣는다. 생성 스크립트에서 모든 근을 원래 식에 대입해 0인지 assert한다.
- 고등학교(H, 24pt)에서 두 칸 연습 장의 긴 식은 `"size": 24` 를 주고, 문제와 핵심 문장이 있는 `steps` 장은 단계 3개까지 쓴다.
