# 과학

- 흐름: 질문 → 예상 → 관찰·실험(집에서 안전하게 할 수 있는 것) → 결과 기록 → 증거로 설명. 결과를 실험 전에 정답처럼 보여 주지 않는다(예상 장과 결과 장을 나눈다).
- 실험은 집에 있는 재료로, 불·전기(콘센트)·뜨거운 물·화학 약품·날카로운 도구가 필요하면 부모가 직접 시범을 보이거나 하지 않는다. 위험이 있으면 `safety`와 노트 주의에 쓴다. 산·염기는 식초·베이킹소다·자주색 양배추 즙처럼 식품 재료만 쓴다.
- 관찰 기록은 활동지 표(`table`)로. 측정이 있으면 단위를 쓴다.
- 과학 용어는 초등 교과서에서 쓰는 말로(예: 증발, 응결, 먹이 사슬). 처음 나올 때 쉬운 말로 뜻을 함께 쓴다.
- 사실은 정확해야 한다. 수치(행성 크기·거리 등)는 대략적인 비교로만 쓰고 확실하지 않은 숫자는 쓰지 않는다.
- 견본: lessons/G03_초3/SCI_과학/ 의 PUSHPULL·SOUND·ANIMAL·ANIMLIFE·PLANTLIFE. 실험 하나 = 네 장: 예상 `table` 장(빈 ‘내 예상’ 칸, 키 “예상은 활동지 N에 써요”) → `activity` 장(steps·criteria ‘관찰할 때 확인해요’·safety) → 결과 `table`/`concept` 장(실험 뒤에만) → 오개념 `compare` 장.
- 활동지는 예상과 결과를 한 표의 ‘내 예상 / 결과’ 칸으로, 단위는 열 제목에(“거리(cm)”), 표는 `widths`로 넓게. 안전은 장의 `safety`(부모용 안내에도 인쇄됨)와 노트 주의에 쓴다.
- 장치 그림(시소·종이컵 전화기·수조)은 `geo`로 실제 좌표에 맞게 그려 기울기·균형이 물리적으로 맞게 한다. 막대·꺾은선그래프는 그 학년 수학에서 배운 뒤에만 쓴다(초3은 표).
- 차시 전체의 안전 수칙은 원본 최상위 `safety`[문장…]에 쓰면 부모용 안내 ‘시작 전에’에 빨간 글씨로 인쇄된다. 결과를 미리 보여 주는 원인→결과 `flow`는 실험 뒤에만 쓴다.

## 중학교(M) 견본에서 정한 것 (중1 온도와 열평형)

- 견본: `lessons/G07_중1/SCI_과학/열과상태변화/KR22-G07-SCI-TEMP-L01.json`, 생성기 `tools/examples/middle/gen_temp.py`.
- 실험은 예상 → 활동 → 결과 → 비교 4장을 그대로 쓰고, 아이 결과 바로 뒤에 `예시`로 표시한 자료 그래프 장을 둔다. 재는 실험은 9분 안팎이므로 다른 장은 짧게, `break_after` 는 결과 장 뒤.
- 입자 모형은 상자마다 같은 개수·같은 크기, 화살표 길이 = 빠르기(방향은 고정한 난수로 정해 그림끼리 길이만 다르게). 뒤 차시(상태 변화·열팽창·기체)도 같은 모형을 쓴다.
- 두 계열 그래프(시간–온도 등)는 `chart` 가 한 계열만 그리므로 `geo` 로 그린다(`gen_temp.py` 의 graph). 예시 자료는 생성기에서 물리적으로 맞는지 assert한다(뜨거운 쪽은 내려가고, 선이 엇갈리지 않고, 양에 비례해 변함).
- 카드 세 장 가로는 한 줄 10자 안팎이므로 두 줄 이내로 짧게.
