# 교육과정 연결

## 자료

- `curriculum/meta.json`: 12개 학년(G01~G12, 학년군 E12·E34·E56·M·H)과 13개 계통 코드.
- `curriculum/grade_items.json`: 학년별 학습 항목 456개. ID `KR22-G05-MAT-I01` (학년·계통·순번). 원본 목차의 "정규 교과 없음" 자리 표시 행(초1·2 영어)은 넣지 않았다.
- `curriculum/units.json`: 기존 331개 단원과 연결 학년. 단원 ID `2.1.2`.
- 다시 만들 때: `python3 -I tools/extract_curriculum.py <초중고 세부 목차.docx> curriculum/`

## 규칙

- 학년 배치와 목표 문장은 교육자료 제작용 **권장안**이다. 학교 교과서의 단원 순서와 같다고 주장하지 않는다.
- 원래 단원·학년 항목을 지우거나 합치지 않는다. 수업은 `curriculum.grade_items` 와 `curriculum.units` 로 다대다 연결한다. 한 수업이 여러 계통에 걸쳐도 주관 계통은 하나다.
- `link_status`: 확인됨(공식 원문과 대조) · 부분 확인(권장 배치와 연결, 코드 미확인) · 자체 확장. 원문에서 확인한 코드만 `standard_code` 에 적는다.
- 적용 시점: 2026학년도 중3·고3은 실제로 2015 개정이 적용된다(2022 개정은 2027학년도부터). 그 학년 아이라면 학교 교과서 단원을 먼저 확인한다.
- 고등학교: 고1은 공통 과목 기반. 고2·3 선택 항목은 아이의 경로에 맞는 것만 고른다. 2028학년도 수능(2025년 고1부터)은 국어 화법과 언어·독서와 작문·문학, 수학 대수·미적분Ⅰ·확률과 통계, 탐구 통합사회·통합과학을 공통으로 본다. 입시가 목적이면 이 과목들을 필수 경로로 다룬다.
- 학년 항목 하나는 여러 차시다. 항목 수를 파일 수로 계산하지 않는다.
