# 웹 교육 자료 (제작 규칙)

같은 원본(`lessons/*.json`)에서 PPTX와 함께 웹 자료를 만든다. 웹은 아이가 직접 조작하고 반복하는 화면이고, PPTX는 부모가 아이와 함께 보며 시범·비교·대화를 하는 화면이다. 두 형식의 내용과 목적은 달라도 된다. 웹에만 필요한 내용은 장·문항의 `web` 필드에 두고, PPTX 생성은 이 필드를 무시한다.

배경 검토: `docs/웹전환_검토.md`, `docs/초1_상세검토.md`.

## 정한 것

| 항목 | 내용 |
|---|---|
| 기기 | 두 기기. 부모 휴대폰(진행, 노트, 정답, 기록) + 아이 태블릿(화면, 조작, 답하기). 아이패드·안드로이드 둘 다 지원한다(iOS Safari, Android Chrome) |
| 배포 | 인터넷 없이 쓸 수 있게 만든다. 한 번 열어 홈 화면에 추가하면 오프라인으로 쓰는 방식(PWA)을 기본으로 하고, 나중에 공개 웹 주소로도 그대로 연다 |
| 두 기기 연결 | 서버 없이 같은 와이파이 안에서 연결하는 방법을 먼저 쓰고, 안 되면 아이 화면에 장 번호를 크게 보이고 부모가 같은 번호를 누르는 방식으로 물러선다 |
| 자동 채점 | 아이 화면에서 한다. 파일에 정답이 들어 있어도 된다(학생용 PPTX의 정답 제거 규칙은 웹에 적용하지 않는다) |
| 그림 | 코드로 직접 그린 단순 아이콘을 쓸 수 있다(아래) |
| 제작 순서 | 초1부터 차례로. 묶음을 고친 뒤 그 묶음부터 웹으로 만든다 |

## 문항의 `web` 필드

노트 문장에만 있던 정답·허용 답·오답 대응을 구조로 둔다. 연습·확인 장의 문항마다(고르기 장은 장에):

```json
"web": {
  "input": "numpad",
  "answer": "8", "accept": ["8", "여덟"],
  "steps": [ { "label": "중간 수", "answer": "10" } ],
  "wrong": [
    { "value": "12", "misconception": "M1", "feedback": "5개 뺐는데 1개만 줄었어요", "goto": "S04" }
  ],
  "say": "열세 개에서 다섯 개를 빼면 몇 개일까요?"
}
```

| 필드 | 뜻 |
|---|---|
| `input` | `numpad`(수 입력) · `choice`(하나 고르기) · `multi`(모두 고르기) · `tap`(그림에서 누르기) · `drag`(끌어 넣기·분류) · `order`(순서 맞추기) · `compose`(자모·숫자 카드 조립) · `trace`(따라 쓰기, 부모가 판정) · `parent`(말로 답함, 부모가 판정) · `none`(채점 안 함) |
| `answer`, `accept` | 정답과 함께 맞음으로 볼 답. 순서가 여럿 맞으면 `order` 의 허용 범위를 적는다(예: 처음과 끝만 고정) |
| `steps` | 중간 단계 칸(중간 수, 가르기 두 칸). 어느 단계에서 틀렸는지 구별한다 |
| `wrong` | 흔한 오답 → 원본 `misconceptions` 의 ID → 아이에게 보일 피드백(정답을 바로 말하지 않고 되묻기) → 돌아갈 장 |
| `say` | 기계 음성이 읽을 문장. 숫자·시각·단위는 읽는 말로 쓴다(“3시” → “세 시”, “13개” → “열세 개”, “8 − 3” → “팔 빼기 삼”). 고유어/한자어를 정해 쓴다 |

- 말로 답하는 문항(두 가지로 읽기, 까닭 말하기, 소리 내어 읽기)은 `parent`: 아이 화면에는 문제만 보이고, 부모 휴대폰에 ‘맞음 · 도움 · 아직’ 단추가 뜬다. 이 결과가 기록표가 된다.
- 정답이 없는 ‘나라면 어떻게 할까’ 고르기는 `none`: 고른 것을 부모 휴대폰에 보내고, 부모가 ‘까닭 말함 / 도움’을 기록한다. 고른 뒤 표정·소리로 정답을 암시하지 않는다.
- 자동 채점 뒤에도 “어떻게 알았어?”를 묻는다. 계산이 맞아도 까닭을 말하지 못하면 개념 목표는 확인 완료가 아니다(`home-tutoring.md`).
- 자동 채점하는 문항은 정답이 하나로 정해지는지 먼저 확인한다. 여럿이면 `accept` 나 허용 범위를 적고, 정할 수 없으면 `parent` 로 둔다.

## 음성

| 구분 | 방법 | 예 |
|---|---|---|
| 기기 음성(TTS) | 기기에 들어 있는 한국어 음성으로 그 자리에서 읽는다. 파일이 필요 없다. `say` 를 쓴다 | 낱말, 지시문, 이야기 읽어 주기, 받아쓰기 불러 주기, 수 읽기 |
| 음성 파일 | 미리 만들어 함께 배포한다. 같은 목소리·같은 높이로 만든다 | 자모 낱소리([그] [끄] [크]), 받침 끝소리([윽] [은]…), 늘였다 줄이는 이어 읽기([그…아] → [가]), 예사·된·거센 세 짝, 문장 부호 억양 대비, 시 낭독, 목소리 비교 |
| 소리 효과 | 코드로 만든다 | 박(70·90·110 BPM), 손뼉·무릎, 효과음 |

- 기계 음성에 자모 낱자(ㄱ, ㅏ)를 그대로 넣지 않는다(‘기역’으로 읽거나 소리를 내지 않는다). 낱소리는 음성 파일로 한다.
- 음성 파일은 처음 쓰기 전에 부모가 한 번 들어 확인하고, 마음에 들지 않으면 부모 휴대폰에서 직접 녹음해 바꿀 수 있게 한다.
- 소리로 구별하게 하는 문제를 만들지 않는 것: ㅐ/ㅔ, ㅚ/ㅙ/ㅞ, ㅒ/ㅖ(표준 발음에서도 구별이 약하다). 뜻으로 고르게 한다.
- 노트의 발음 표기 [ ]와 기계 음성이 다르게 읽지 않게, 쓴 대로 소리 나지 않는 낱말(참외[차뫼], 열쇠[열쐬])은 한글 단원의 예에서 피한다.

## 그림(아이콘)

- 물건 하나·기호 하나를 나타내는 단순 아이콘을 SVG 코드로 직접 그린다. 생성형 이미지와 사진은 쓰지 않는다.
- 아이콘 안에 수량·글자를 넣지 않는다. 수량은 기존 그림(배열, 십 칸 틀, 수 모형)으로 나타낸다.
- 아이콘마다 이름을 붙이고, 같은 이름은 어디서나 같은 아이콘으로 쓴다. 사람 아이콘은 성별·나이가 한쪽으로 치우치지 않게 한다.
- 글을 못 읽는 아이가 혼자 할 수 있게, 분류·고르기 문항의 낱말에는 아이콘과 소리 단추를 함께 둔다.

## 조작 부품

차시마다 따로 만들지 않고 부품으로 만들어 쓴다. 부품의 상태는 원본의 그림 명세(`tenframe`, `blocks10`, `clock` …)와 같은 값을 쓴다.

| 부품 | 쓰는 곳(초1) |
|---|---|
| 십 칸 틀·돌 끌기(세기, 가르기·모으기, 10 만들기, 옮기기, 덜기) | NUM9, COMPOSE, MAKE10, CARRY, BORROW |
| 누르며 세기(다시 누르면 “벌써 셌어요”) | NUM9, ADD |
| 수 모형 판(10개 묶기·풀기) | NUM50, NUM100, NUMSEQ, ADD2D |
| 자모 조립·반절표(받침 자리, 받아쓰기 채점) | 한글 단원 |
| 손글씨 따라 쓰기(필순 보기 → 따라 쓰기) | NUM9, VOWEL, CONS … |
| 시곗바늘(연동 모드, 따로 모드) | CLOCK, MYDAY |
| 분류 바구니(예/아니요, 여러 종류) | SORT, SHAPE3D, PRIVACY, SAVE, PROMISE |
| 순서 카드(허용 범위 있는 채점) | MYDAY, SMALLSTEP, HANDWASH, DEVICE |
| 짝 짓기 비교 | NUM9ORD, SUB, EVENODD |
| 수 배열표 | NUMPAT, NUMSEQ |
| 끝 맞추기, 저울·붓기(예상한 뒤 확인), 모양 돌리기, 박 맞추기 | LENGTH, COMPARE, SHAPE3D, BEAT |
| 느낌 고르기(얼굴 그림+소리), 실천표(○/△) | 통합 차시 |

## 자동으로 만드는 연습

- 연습량이 부족한 내용은 웹이 문제를 만들어 반복한다. 틀린 문제는 간격을 두고 다시 낸다. 통과 기준(예: 연속 10문제 중 9개, 한 문제 5초 안)을 정한다.
- 초1 수학 사실 줄기: 10의 짝 → 10 − □ → 10 + 몇 → 받아올림 36개 → 받아내림 36개.
- 생성기는 원본의 `checks` 와 같은 계산기로 정답을 만든다. 만든 문제의 그림 수량이 정답과 맞는지 검사한다.

## 화면으로 대신하지 않는 것

- 실물 조작(바둑돌·콩 묶기·저울·물 붓기), 몸 활동(달리기·박·손 씻기), 실제 관찰(하늘·생물), 만들기·그리기, 역할 놀이와 대화, 그림일기.
- 이런 장은 웹에서 ‘짧은 안내 + 다 했어요’로 두고, 결과는 부모 휴대폰의 기록표에 남긴다. 화면 속 놀이로 같은 활동을 대신하지 않는다.
- 관찰 차시는 아이가 관찰을 마치기 전에 결과 화면이 열리지 않게 잠근다.
- 신체 경계·낯선 사람·학대 신고는 점수·별·‘틀렸어요’ 소리가 있는 게임으로 만들지 않는다. 대화로 한다.

## 웹 자료가 지킬 약속

- 부모가 정한 수업 시간을 아이 화면에 남은 시간 막대로 보인다. 끝나기 2~3분 전 “곧 끝나요”, 끝나면 “다 했어요 → 끄고 제자리에” 화면에서 멈춘다. 20분쯤 눈 쉬기를 안내한다.
- 아이가 이름·주소·사진을 넣는 칸을 두지 않는다. 아이 이름은 부모 휴대폰에서만 쓴다.
- 바깥 링크·광고·채팅·결제가 없다.
- 기록은 기기 안에만 저장한다. 공개 웹이 되어도 아이 정보를 밖으로 보내지 않는다.
- 아이 화면에 늘 ‘어른 불러요’ 단추를 둔다(두 기기가 연결되어 있으면 부모 휴대폰에 알림).

## 검사

- 장마다 고정 16:9 무대에서 글 넘침을 브라우저에서 실제로 잰다.
- `web` 필드: 정답이 원본 `checks`·노트와 같은지, `wrong` 의 오개념 ID가 원본에 있는지, `goto` 장이 있는지.
- 아이 화면에 정답이 미리 보이지 않는지(그림 `alt`, 캡션, 칸 수).
- 아이패드 Safari와 안드로이드 Chrome에서 열어 조작·소리·기록 보존을 확인한다. 확인하지 못한 기기는 통과로 적지 않는다.
