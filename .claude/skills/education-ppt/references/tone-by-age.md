# 연령에 맞는 표현

아이가 보는 글(화면과 활동지)은 아이의 나이에 맞는 말투·문장 길이·낱말·등장인물로 쓴다.
초등 저학년에게는 어렵지 않게, 중·고등학생에게는 유치하지 않게 쓰는 것이 목표다.

부모 노트는 모든 학년에서 ‘~합니다’체로 쓰고, 노트 안에서 아이에게 건네는 말(따옴표 안)은 부모가 평소 아이에게 하는 말로 쓴다. 아래 기준은 **아이가 보는 글**에만 적용한다.

## 학년군별 기준

| 학년군 | 말투 | 문장 | 낱말 | 등장인물 |
|---|---|---|---|---|
| 초1·2 (E12) | 짧은 해요체(세어요, 읽어 봐요) | 한 문장 15자 안팎, 길어도 30자. 한 문장에 한 가지 | 교과서에 나오는 쉬운 말. 아직 안 배운 낱말·한자어는 쉬운 말로 풀거나 쓰지 않는다 | 토끼·곰 같은 동물, 가·나 |
| 초3·4 (E34) | 해요체 | 25자 안팎, 길어도 38자 | 새 용어는 처음 나올 때 뜻과 함께 | 동물 또는 사람 이름, 가·나 |
| 초5·6 (E56) | 해요체 | 30자 안팎, 길어도 45자 | 교과 용어를 쓰되 처음 나올 때 뜻과 함께 | 사람 이름(지호·서윤 등), 가·나. 동물 캐릭터는 쓰지 않는다 |
| 중학교 (M) | 교과서식(아래) | 2문장 이내 | 교과서 용어 그대로 | 사람 이름, 가·나 |
| 고등학교 (H) | 교과서식(아래) | 2문장 이내, 간결하게 | 교과서 용어 그대로 | 사람 이름, 가·나 |

- 초5 이상에서는 어린아이에게 하듯 하는 꾸밈말(“짠!”, “우와!”, “친구들”)을 쓰지 않는다.
- 문제의 소재도 나이에 맞춘다. 중·고등학생 문제에 사탕 나누기·동물 친구 같은 유아 소재를 쓰지 않는다.

## 중·고등학교의 교과서식 말투

해요체(‘풀어요’, ‘~예요’, ‘~일까요?’)를 쓰지 않는다. 쓰임에 따라 다음 꼴로 쓴다.

| 쓰임 | 꼴 | 예 |
|---|---|---|
| 설명·정리·핵심 | ~이다 / ~한다 | 부등식에서도 부호를 바꿔 항을 옮길 수 있다. 이것이 이항이다. |
| 풀이 단계 | ~한다 | 양변에서 3을 뺀다. / 계산한다. |
| 장 제목·활동 이름 | 명사형 또는 ~하자 / ~해 보자 | 부등식에서의 이항 / 해를 수직선에 나타내자 |
| 화면의 연습 안내(함께 하는 활동) | ~하자 / ~해 보자 | 풀고 수직선에 나타내 보자. |
| 활동지·마무리 확인 문제의 지시문 | ~하시오 | 다음을 풀고, 해를 수직선에 나타내시오. |
| 질문 | ~일까? / ~는가? / ~인가? | 누구의 말이 맞을까? |
| 표지의 목표 | ~할 수 있다 | ① 부등식의 성질로 일차부등식을 풀 수 있다. |
| 힌트·주의 | ~한다 / ~하자 | x의 계수가 음수이면 나눌 때 방향을 바꾼다. |

그대로 두는 것(말투를 바꾸지 않는다):

- 인물의 말(따옴표 안의 말, ‘누구의 말이 맞을까?’ 장의 양쪽 말).
- 읽기 지문, 학생 글 예시, 인용문, 대화문, 편지·안내문 같은 글 자료.
- 국어 문법·높임법·문체를 다루는 장의 예문(예문의 말투가 공부할 내용이다).
- 영어 과목의 영어 문장.
- 명사로 끝나는 짧은 말(‘혼자 해 보기’, ‘오늘 배운 것’, ‘○ 정답’).

## 도구가 넣는 문구

정리 장의 복습 안내와 활동 장의 기준 카드 제목은 도구가 학교급에 맞춰 넣는다(초등 ‘다음 수업을 시작할 때 다시 풀어요’, 중·고 ‘다음 수업을 시작할 때 다시 풀어 보자’).
