# 수업 설계: 목표 → 증거 → 활동

## 한 차시의 크기

- 중심 개념 또는 수행 하나, 관찰 가능한 목표 1~3개. 설명·학생 활동·피드백이 예정 시간 안에 끝나야 한다.
- 새로운 선수 개념을 따로 배워야 하거나 독립 평가가 필요한 목표가 생기면 차시를 나눈다.
- 장 수는 할당량이 아니다. 내용을 늘려 채우지 않는다.

## 목표 쓰기

- 행동 + 조건 + 확인 방법 + 성공 기준. 예: "크기가 같은 분수를 이해한다" → "같은 전체를 나타내는 두 그림에서 2분의 1과 4분의 2가 같은 양임을 설명한다".
- 목표마다 가르치는 장(teach), 해 보는 장(practice), 확인하는 장(check)을 연결한다. `check_lesson.py` 가 검사한다.
- 모든 목표를 객관식으로 바꾸지 않는다. 설명·그림·풀이 과정·작품·관찰 기준으로 확인한다.

| 목표의 행동 | 확인 활동 |
|---|---|
| 설명한다 | 말·그림·모형으로 설명하고 이유 말하기 |
| 비교한다 | 기준을 정해 공통점·차이점·예외 정리 |
| 해결한다 | 방법을 골라 풀고 과정과 타당성 점검 |
| 탐구한다 | 질문·방법·자료·결론·한계가 있는 결과물 |
| 평가한다 | 근거와 기준으로 대안을 판단하고 반론 검토 |
| 실천한다 | 계획·실행·관찰·수정 기록 |

## 장의 역할 (`role`)

intro(오늘의 질문·목표) · prior(선수 확인) · teach(설명·시범) · practice(도움 받는 연습·오개념 비교) · check(혼자 하기·마무리 확인) · feedback(정답과 피드백, 교사 전용) · review(정리·다음 복습) · support(보충, 필요할 때만)

## 기본 흐름

이전 학습 확인 → 작은 단계로 설명·시범 → 도움 받는 연습 → 혼자 하기 → 피드백 → 정리와 다음 복습.
풀이 예제와 직접 풀기를 번갈아 하고, 구체물·그림을 식·기호와 연결하고, 기억에서 꺼내 답하는 복습을 넣는다.

## 오개념

- 원본 `misconceptions` 에 흔한 오개념과 대응을 적고, 적어도 하나는 장으로 직접 다룬다(그림으로 반박하기).
- 규칙만 외우게 하지 않는다. "무엇이 바뀌고 무엇이 그대로인가"를 묻는다.

## 정답 검산

- 계산 가능한 답은 모두 `checks` 에 넣는다(equiv, not_equiv, blank, bar). 해설을 다시 읽는 것으로 끝내지 않고 계산으로 검산한다.
- 여러 답이 가능한 문항은 판단 기준과 가능한 답의 범위를 노트·안내서에 적는다.
