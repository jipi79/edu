# edu — 초중고 학년별 교육 자료

집에서 부모가 아이를 1:1로 가르칠 때 쓰는 보충 학습 자료를 만드는 저장소입니다.
한 차시마다 수업용 PPT, 학생용 PPT, 활동지, 부모용 진행 안내를 만듭니다.

## 바로 쓰기

만들어진 자료는 `dist/학년/과목/단원/` 에 있고, 전체 목록은 [lessons/INDEX.md](lessons/INDEX.md) 에 있습니다.

| 파일 | 누가, 어떻게 |
|---|---|
| `…_부모용안내.pdf` | 부모가 인쇄하거나 휴대폰으로 봅니다. 장별 발문, 예상 답, 정답, 막힐 때 할 일, 기록표 |
| `….pptx` (수업용) | 아이와 함께 **슬라이드 쇼**로 봅니다. 노트에 정답이 있으니 일반 보기 화면은 보여 주지 마세요 |
| `…_활동지.pdf` | 아이가 씁니다. 정답이 없습니다 |
| `…_학생용.pptx` | 아이가 혼자 복습할 때. 정답 장과 노트를 뺐습니다 |

## 구성

| 경로 | 내용 |
|---|---|
| `curriculum/` | 「초중고 세부 목차와 학습 목표」에서 추출한 데이터: 12개 학년, 13개 계통, 학습 항목 456개, 기존 단원 331개 |
| `lessons/` | 수업 원본(JSON). 모든 자료는 여기서 생성합니다 |
| `dist/` | 생성된 PPTX·PDF |
| `tools/` | 목차 추출, PPTX 생성, 활동지·안내 PDF 생성, 전체 빌드 스크립트 |
| `.claude/skills/education-ppt/` | 수업 설계 규칙, 원본 스키마, 검사 스크립트 (Claude Code 스킬) |

## 만들기

```bash
npm install                     # pptxgenjs
tools/build.sh lessons/G05_초5/MAT_수학/분수의성질/KR22-G05-MAT-FRAC-EQUIV-L01.json
```

`build.sh` 는 원본 검사(목표 연결, 정답 검산, 그림과 분수 표기의 일치) → PPTX 두 벌 → 활동지·부모용 안내 PDF → 출력 검사 → 목차 갱신을 차례로 합니다.
필요한 것: Node 18+, Python 3 (`python-pptx`, `jsonschema`, `python-docx`), Playwright(Chromium), LibreOffice(선택, 안내서의 장 미리보기용).

## 기준

학년 배치와 목표는 2022 개정 교육과정 계열의 **권장안**입니다. 공식 성취기준 코드는 원문으로 확인한 것만 기록합니다.
실제 수업에서는 아이 학교의 교과서 단원 순서를 확인하세요.
