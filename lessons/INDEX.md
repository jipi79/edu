# 수업 목차

`tools/build.sh`가 수업 원본(JSON)에서 자동으로 만드는 파일입니다. 직접 고치지 마세요.

- 제작된 수업: 16차시
- 수업이 하나 이상 연결된 학년 항목: 6 / 456

상태: 계획 → 원고 완료 → 제작 완료(자동 검사 통과) → 검토 완료(사람이 확인) → 배포. 실제 아이에게 수업한 효과는 별도로 기록합니다.
