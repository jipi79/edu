# 초등 차시 계획 원본

학년별 `G01.txt` … `G06.txt` 에 차시를 적고 `python3 -I tools/plan/build_plan.py` 로
`plan.json`(데이터)과 `../초등_차시계획.md`(목차)를 만든다.

```
@ MAT-I01 | 수와연산 | 2.1.1 2.2.1            ← 학년 항목 | 단원 폴더 | 연결 단원 [| act] [| pri N]
- NUM9 | 9까지의 수 | 0부터 9까지의 수를 …    ← 개념 코드 | 제목 | 목표 [| pre G01-MAT-NUM50, …]
```

- 수업 ID: `KR22-<학년>-<계통>-<개념 코드>-L01`. 같은 개념 코드가 다시 나오면 L02, L03…
- 선수 차시: 같은 항목 안에서는 바로 앞 차시가 자동으로 들어간다. 다른 항목·학년의 선수 차시는 `pre` 로 적는다.
- 형식: 기본은 `ppt`(설명·연습 중심). `act` 는 화면이 짧은 안내이고 활동지가 관찰·실천 기록인 활동 중심 차시.
  음악·미술·체육 실기, 기술·가정, 진로, 환경은 기본 `act`.
- 우선순위: 1 = 국어·수학·영어(누적형, 결손이 이후 학습을 막음), 2 = 과학·사회, 3 = 그 밖.
