# 중학교 견본 차시의 원고 생성 스크립트

중학교 견본 차시(소수와 합성수·정수와 유리수의 덧셈·온도와 열평형·위도와 경도, 중3 제곱근)를 만들 때 쓴 내용 JSON 생성기와 도우미다.
도구가 아니라 **참고용 예시**이며, 비슷한 그림이 필요할 때 함수를 가져다 쓴다. 생성기마다 정답·자료를 assert로 검산한다.

| 파일 | 쓸 만한 것 |
|---|---|
| `nl.py` | `geo` 수직선: 음수 눈금(−), 색이 다른 이동 화살표, 끝 점 |
| `prime.py`, `intadd.py` | 수학 차시 원고 구성, 체(격자) 그림, 부호 있는 분수 `eq`, 검산 assert |
| `geo_common.py` | `geo` 선분·글자·호 도우미, 선끼리 겹침 검사 |
| `gen_temp.py` | 입자 모형 상자(같은 개수·크기, 화살표 길이 = 빠르기), 두 계열 시간–온도 그래프, 온도계, 실험 장치 |
| `gen_latlong.py` | 위도·경도 격자, 옆·위에서 본 지구, 시차 계산과 검산 |
| `radical.py` | (중3 제곱근·곱셈 공식) 화면 식 읽기, 근호 수 `Rad`(a√b 정확 계산), 다항식 전개 `Poly`, 수직선 도우미 |

경로가 작업 폴더 기준으로 적혀 있을 수 있으니 고쳐 쓴다. 출력 내용 JSON은 `tools/plan/fill_lesson.py`로 뼈대에 합친다.
