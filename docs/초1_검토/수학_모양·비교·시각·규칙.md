# 초1 수학 모양·비교·시각·규칙 차시 검토

검토일: 2026-11-15 · 원본 파일은 고치지 않았다.

검토 대상 (7개 차시):

- 모양과비교: SHAPE3D, SHAPE2D, LENGTH, COMPARE
- 시간과규칙: CLOCK, PATTERN, NUMPAT

그림은 `--raw` 좌표, 렌더러 코드(`tools/pptx/figures.js`, `tools/handouts/build_handouts.js`), dist의 PPTX·활동지 PDF를 렌더링한 미리보기로 다시 확인했다.

## 그림 검증 결과

- 시계: 모든 시계(슬라이드·활동지)가 `h + m/60` 으로 계산된다. 그래서 몇 시 30분이면 짧은바늘이 정확히 두 수 가운데에 있다. 문제 없음.
- 길이 띠: 모두 한쪽 끝이 맞춰져 있다. S08만 일부러 어긋나게 그렸다.
- 탑·컵: 아래(바닥)가 모두 맞춰져 있다.
- 규칙 배열·수 배열표: 모든 칸과 빈칸, 강조 위치가 맞다.
- 정식 용어: 아이가 보는 글에 삼각형·사각형·원·시침·분침 같은 정식 용어는 없다.

- [보강-하] S13, 활동지 6, S14 복습 ③이 거의 같은 문항이다(답은 모두 공 모양). → 마무리 확인을 처음 보는 유형으로 바꾼다(예: "세우면 쌓이고 눕히면 굴러가는 물건은?").
- [제안] 교과서 활동 셋이 빠져 있다: 주머니 속 물건 만져서 맞히기, 일부만 보고 맞히기, 모양으로 만들기(기차·로봇을 만들고 쓴 모양 세기). 1:1 가정 학습에 잘 맞고 성취기준의 '만들기'도 채우므로 S10 뒤에 5분 활동으로 넣는다.
- [제안] S09·활동지: 둥근기둥이 늘 세워진 그림뿐이다. 눕힌 둥근기둥과 세운 길쭉한 상자를 섞어, 놓는 방향이 달라도 같은 모양임을 보인다.
- [표현] S08·S11·S13과 활동지 1·2·5는 물건 이름 글자만 있다. 아이가 혼자 읽어야 한다. → 그림을 붙이고, 모든 장 노트에 "부모가 읽어 줌"을 적는다.
- [웹] 3D 회전: S03~S05에서 아이가 손가락으로 모양을 돌리고, 평평한 곳을 누르면 그곳이 칠해진다. 공은 칠해지는 곳이 없다. 공과 동그라미의 차이, 눕힌·세운 둥근기둥을 보여 준다.
- [웹] S08·S09 분류: 물건 그림을 바구니 3개로 끌어 놓고 자동 채점한다. 오답별 피드백은 다음과 같다.
  - 캔을 공 바구니에 넣음(M2) → "캔을 세울 수 있니?"
  - 길쭉한 상자를 상자 바구니 밖에 둠(M1) → "크기 말고 평평한 곳·뾰족한 곳을 봐"
  - 물건 그림 은행(30개쯤)에서 문제를 자동으로 낸다. 지시문은 TTS로 충분하다.
- [웹] 화면으로 대신하면 안 되는 것: S03~S05 만져 보기, S06 굴리고 쌓기, S08 실물 나누기.
- [역할] PPTX: 실물 탐색을 이끄는 진행 화면 / 웹: 실물 활동 뒤 그림 분류, 특징 퀴즈, 3D 회전 관찰.

### KR22-G01-MAT-SHAPE2D-L01 네모·세모·동그라미 모양 — 보강 필요도: 중 (돌려 놓은 모양을 다루지 않고, 연습 물건이 설명한 예와 같음)
- [오류] S02 다(공 모양)·S15: 위의 sphere 문제가 그대로 있다. 이 차시는 '상자 모양'과 '네모 모양'을 가르는 차시(M2)라, 다를 '동그라미'로 보게 만드는 그림이 특히 해롭다.
- [보강-중] M1의 "거꾸로 놓인 세모"와 목표 A 성공 기준의 "돌려 놓은 모양"을 보여 주는 그림이 없다. S05는 바로 선 세모와 직각 세모뿐이고, S08은 네모만 다룬다. S11·S13·활동지에도 없다. → S08에 거꾸로 된 세모와 기울인 네모를 넣고, S11이나 활동지 2에 돌린 모양에 이름 붙이기 문항을 넣는다.
- [보강-중] S07과 활동지 1의 물건(동전·공책·삼각김밥·접시·창문·옷걸이)이 S04~S06에서 예로 든 것과 같다. 그래서 새 물건에 적용하는지가 아니라 기억만 확인한다. → 단추·시계·액자·피자 조각·표지판·트라이앵글처럼 처음 보는 물건으로 바꾼다.
- [표현] S08 토끼의 말 “나는 길쭉해서 네모가 아니에요.”: '나'가 토끼인지 '나' 도형인지 헷갈린다. 토끼가 길쭉하다는 뜻으로도 읽힌다. → "토끼: “나 모양은 길쭉해서 네모가 아니에요.”"
- [제안] S09 시범 그림은 조각 셋을 나란히 늘어놓았을 뿐 '꾸민 그림'이 아니다. S13도 "물고기를 꾸민 조각"이라면서 물고기 모양이 없다. → 실제로 맞붙인 집과 물고기 그림을 보여 주고 그 위에서 세게 한다.
- [노트] S03 대고 그리기에 쓸 세모 물건이 준비물에 없다. → "세모 물건이 없으면 색종이 세모 조각을 대고 그린다"를 한 줄 넣는다.
- [웹] 뾰족한 곳 누르기: 누를 때마다 점이 찍히고 수가 올라간다. 같은 곳을 다시 누르면 "이미 셌어요"라고 알려 준다(M3). 모양을 돌리고 늘여도 개수가 그대로임을 보여 준다(M1). 모두 자동 채점한다.
- [웹] 꾸미기: 조각을 끌어 그림을 만들면 화면이 모양별 개수를 센다. 아이가 센 수와 비교해 목표 B를 자동으로 확인한다.
- [웹] 화면으로 대신하면 안 되는 것: S03 대고 그리기, S10 색종이 조각 꾸미기, S11 ③ 집에서 네모 찾기.
- [역할] PPTX: 본뜨기와 특징 설명 / 웹: 꼭짓점 세기, 돌리기, 끌어서 꾸미기와 자동 개수 세기.

### KR22-G01-MAT-LENGTH-L01 길이와 높이 비교 — 보강 필요도: 중 (핵심 성공 기준을 혼자 확인하지 않고, M3를 반박하는 그림이 없음)

### KR22-G01-MAT-COMPARE-L01 무게·넓이·담을 수 있는 양 비교 — 보강 필요도: 상 (분량이 넘치고, 그림 오개념 M2·M4를 그림으로도 확인 문항으로도 다루지 않음)
- [보강-상] 옷걸이 저울(무게), 겹치기(넓이), 물 붓기(담을 수 있는 양) 세 가지 실물 활동을 40분에 모두 한다. 준비·정리까지 넣으면 실제로는 50분이 넘는다. → 2차시로 나눈다: ① 무게 ② 넓이와 담을 수 있는 양. 지금 쉬는 지점(break_after S05)에서 나누면 첫날에는 무게를 혼자 확인하는 장이 없으니, S05 뒤에 무게 확인 문항을 넣는다.
- [보강-상] M2(위로 올라간 쪽이 무겁다)는 그림을 보고 판단할 때 생기는 오개념인데, 옷걸이 저울 그림이 어디에도 없다. S03은 글로 쓴 단계뿐이다. → S03에 한쪽이 내려간 저울 그림을 넣고, S11과 활동지에 '어느 쪽이 더 무거워요?' 저울 그림 문항을 넣는다.

  - → S09에 가늘고 긴 컵, 넓고 낮은 그릇, 넘친 장면을 그리고 확인 문항을 하나 넣는다.
- [보강-중] 컵(S01·S08·S13·활동지 3)을 6칸 격자 기둥으로 그려 앞 차시의 블록 탑과 똑같아 보이고, 칸을 세게 만든다. 활동지 2의 종이도 칸 격자라 넓이를 칸 수로 재는 쪽으로 이끈다(범위 밖). → 칸선 없는 컵 윤곽과 물 높이, 칸선 없는 사각형으로 바꾼다.

## 묶음 종합

### 차시 사이의 문제
- 순서와 '다음 시간' 안내는 계획과 맞다.
- 같은 예의 반복:
  - '키가 더 ○○': LENGTH S12·S13·활동지 3, COMPARE S02 ②
  - 컵 4칸/2칸: COMPARE S08과 활동지 3
  - 공책·창문 등: SHAPE2D S04·S07·활동지 1
  - 귤/오렌지: SHAPE3D
- 빈틈:
  - SHAPE3D: 모양으로 만들기
  - CLOCK: 12시 30분
  - NUMPAT: 1~100 전체 표, 위로 가는 문항
- 같은 칸 격자(grid) 그림이 탑(LENGTH), 컵(COMPARE), 종이(COMPARE 활동지 2), 띠(LENGTH 활동지), 색 규칙(PATTERN) 다섯 가지를 나타낸다. 앞 차시의 '탑'과 다음 차시의 '컵'이 똑같아 보인다.

### 공통 패턴
1. 그림 도구의 한계가 개념을 흐린다:
   - sphere가 평면 원으로 그려짐
   - 칸선 있는 격자 때문에 직접 비교가 칸 세기로 바뀜
   - letters 그림의 줄 번호가 문제 타일 안에 들어감
   - 차시 원본보다 `figures.js` / `build_handouts.js` 를 고치는 편이 효과가 크다.
2. 오개념 목록에는 있지만 그림이나 확인 문항으로 다루지 않는 것: SHAPE2D M1, LENGTH M3, COMPARE M2·M4, CLOCK의 12시 30분.
3. 혼자 하기와 마무리 확인이 성공 기준의 핵심을 재지 못한다(LENGTH 끝 맞추기, SHAPE3D 6개 중 5개, COMPARE 상식 문항). 측정 차시의 확인이 그림과 말뿐이니 실물 문항을 하나씩 넣어야 한다.
4. 아이 화면에 글만 있는 장과 활동지 낱말 보기가 많다(SHAPE3D S08·S11·S13, SHAPE2D S07·S11, COMPARE S03·S04·S09~S11). 노트에 "부모가 읽어 줌"을 모든 장에 일관되게 적고, 웹에서는 TTS와 그림을 함께 쓴다.
5. 부모 준비 부담: 손으로 그리는 시계와 1~100 표, 옷걸이 저울의 수평 맞추기. 인쇄물과 노트로 줄인다.
6. 웹 전환 공통:
   - 그림 alt 글에 정답이 들어 있다(CLOCK S14 보기 "(8시 30분)", SHAPE3D S09 각 그림 "상자 모양" 등). 아이 화면에서는 중립 문구로 바꾼다.
   - 연습 정답 다수가 노트 문장에만 있다(SHAPE3D S08, SHAPE2D S07, LENGTH S07, COMPARE S04, PATTERN S06 등). 자동 채점용 정답 필드로 옮겨야 한다.

### 우선순위 상위 5
1. `figures.js` 의 sphere에 입체 단서를 넣는다. SHAPE3D·SHAPE2D의 8장이 바뀌고, 공·동그라미 혼동(M4·M2)을 바로 줄인다.
2. COMPARE를 2차시로 나누고, 저울 기울기와 옮겨 붓기 그림, M2·M4 확인 문항, 실물 확인 문항을 넣는다.
3. LENGTH: 끝이 안 맞은 그림을 혼자 판단하는 문항, M3 반례(블록 크기·바닥), 활동지의 칸 없는 막대, S04 기준선 길이.
4. 줄 번호 타일 분리(PATTERN S06·S09·S11, NUMPAT S05·S10)와 칸선 없는 컵·띠·탑 그림 옵션. 여러 차시가 한 번에 좋아진다.
5. CLOCK: 12시 30분과 '지나온 수' 노트, S14 보기를 7시 30분으로, 그리기 안내 연습 추가. 웹 시곗바늘(연동·따로 모드와 오답별 피드백)을 이 묶음에서 가장 먼저 만들 웹 조작물로 권한다.
